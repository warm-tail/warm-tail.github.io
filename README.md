# Тёплый хвост

Учебный интернет-магазин одежды для маленьких собак и кошек (тема 19, «Разработка сайта и организация процесса электронной коммерции»).

Сайт: https://viktoriya0714.github.io/teply-hvost/

Каталог с фильтрами, карточки товаров, калькулятор размера, корзина и оформление заказа работают прямо в браузере. Заказы никуда не отправляются, оплата не списывается.
